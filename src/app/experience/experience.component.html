The Story Behind The Code

🎓

2015-2021: The Foundation

Started my journey at FAST-NUCES, one of Pakistan's premier tech universities. While studying Computer Science, I dove into web development, discovering my passion for creating beautiful, functional user interfaces.

✍️

2020: First Professional Steps

Joined CarSpiritPK as System Admin & Content Writer. Optimized web vitals, improved performance by 40%, and learned the importance of user experience. This taught me that great code isn't just about functionality—it's about speed and accessibility.

👨‍💻

2021: Junior Developer Era

Stepped into professional development at Hardstone Enterprises. Created interactive dashboards, mastered Redux, reduced API calls by 70%. This was where I transformed from a hobbyist to a professional engineer.

🚀

2022-2024: The Web3 Revolution

At Avento Labs, I led cutting-edge Web3 projects. Built NFT marketplaces, crypto wallets, and integrated with Ethereum and Tron blockchains. Led a team, mentored juniors, and pushed the boundaries of what's possible with modern frontend frameworks.

🎯

2024-Present: Leadership & Innovation

Currently leading frontend at SOCO Engineers. Reduced critical app load time from 30s to 3s. Ported legacy systems to modern stacks in record time. Built hiring pipelines and engineering standards. Now I don't just write code—I shape how teams write code.

🌟

What's Next?

The journey continues. I'm focused on architectural excellence, performance optimization, and building teams that ship quality code. Every project is an opportunity to learn, every challenge is a chance to innovate.
